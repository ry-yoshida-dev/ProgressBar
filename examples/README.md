# examples

## Overview

Runnable scripts demonstrating the package. Install the project first, for
example with `pip install -e ".[all]"`, so that every backend can be shown.

## Components

| Component | Responsibility |
| --- | --- |
| [showcase.py](showcase.py) | `BackendShowcase`, running the same workload with the automatic choice and with every installed backend. |

## Examples

```bash
python examples/showcase.py
```
